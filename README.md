# Bible Study Library

The UTF-8 text files use Markdown headings for document sections. When indexing
passages, retain the filename and the nearest section, verse, question, or page
reference so that answers can be traced to their source.

| Collection | Reading and citation structure |
| --- | --- |
| [KJV BIBLE](KJV%20BIBLE/) | Complete King James Version. Each verse includes its book, chapter, and verse. Original chapter markers are retained. |
| [OT and EBC](OT%20and%20EBC/) and [NT and EBC](NT%20and%20EBC/) | Bible text and Expanded Biblical Comments. KJV chapter headings identify scripture. Commentary headings retain the original reference markers. |
| [Merged_Reprints](Merged_Reprints/) | Reprint text divided at original `[R… : page …]` markers and into shorter paragraphs. Reference numbers and source order are retained. |
| [V1-V3.txt](V1-V3.txt), [V4-V5.txt](V4-V5.txt), and [V6.txt](V6.txt) | Studies in the Scriptures. Series, study, and printed-page markers provide context. Broken word hyphenation is repaired where the spelling can be established. |
| [htdbQAdata.txt](htdbQAdata.txt) | Questions and answers. Each question has a heading with its original `Qpage:item` reference. Dates and answer text are retained. |
| [PHOTODRAMA.txt](PHOTODRAMA.txt) | Sections use the original `[PD…]` reference markers. |
| [Merged_CQ](Merged_CQ/README.md) | Christian Questions Rewind show notes with episode headings and source links. |

## Text companions for the PDFs

Each companion identifies its source PDF and includes a heading for every PDF
page. These page numbers are the PDF viewer's page positions. Printed page
numbers can differ. Pages requiring optical character recognition are marked
`[OCR]`. Consult the corresponding PDF page for charts, illustrations, table
layout, and uncertain OCR wording.
