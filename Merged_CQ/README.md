# Christian Questions Rewind

These UTF-8 text files contain Christian Questions Rewind show notes. Use each
`## Episode` heading as a document boundary when indexing the collection. Keep the
episode number, title, publication date, and source URLs with each passage if
you split the notes further.

The update covers the archive through November 16, 2026. Newly added notes and
five recovered legacy episodes include direct Rewind PDF links. Use those PDFs
for original graphics, tables, layout, and for checking marked OCR pages.
The older volumes may retain irregularities from the original text extraction.
